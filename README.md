# Uber Ride Booking Analysis - NCR Region

End-to-end Data Analysis project on Uber NCR Ride Bookings using Python for Data Cleaning and Power BI for Dashboard.

## 📂 Files in this Repository
- `ncr_ride_bookings.csv` - Raw Data
- `NCR_Ride_Booking_clean_Data.csv` - Cleaned Data
- `Uber.py` - Data Cleaning & Analysis using Python (Pandas)
- `Uber.pbix` - Power BI Dashboard

## 🛠️ Tech Stack
- Python (Pandas, NumPy)
- Power BI

## 📌 Project Steps
1.  Data Cleaning in Python: Removed null values, handled cancelled rides, fixed date/time format.
2.  Data Analysis: Analyzed booking status, revenue, vehicle type, payment method.
3.  Dashboard in Power BI: Created interactive visuals for business insights.

## 📊 Key Insights from Dashboard
- Total Bookings & Total Revenue
- Booking Status (Completed, Cancelled by Customer, Cancelled by Driver)
- Top Vehicle Type and Payment Method
- Peak Booking Hours & Top Locations
- Customer & Driver Rating Analysis
- Reasons for Cancellation

## 🚀 How to Run
1.  Clone this repository
2.  Run `Uber.py` to get clean data
3.  Open `Uber.pbix` in Power BI Desktop
